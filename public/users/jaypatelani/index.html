Raid5 slow write on big disks?

smurfd $ doas newfs -O2 -s 21900g -b 65536 -F NAME=island That command above isn't correct: you don't need to specify a size ( newfs will get it from the kernel); and you shouldn't use -F (which is meant for disk image files--not block devices). Just do: doas newfs -O2 NAME=island # or, /dev/rdk7 BTW, there was a thread about write performance on HW RAID a while back. Try turning WAPBL on as recommended there .
