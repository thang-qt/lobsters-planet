rust-petname 3.0.0 released

rust-petname 3.0.0 is out! rust-petname is fairly simple: it generates random human readable names. It can be used as a library in your Rust projects, or as a command-line application, typically by running cargo install petname . There are breaking changes in the library if you’re upgrading from 2.x, but the command-line tool is largely unchanged. Please read the notes to find out how to upgrade.
